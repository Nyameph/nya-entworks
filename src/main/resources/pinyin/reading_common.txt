# 补录常用读音表（人工维护）——词典里**没有**、但现代汉语／歌词里真的会这么唱的读音。
#
# 与 reading_rare.txt 是同一套分级的两个方向：
#   reading_rare.txt   词典里有，但实际很冷门      → 从「常用」降到「生僻」
#   reading_common.txt 词典里根本没有，但实际常用  → 补进「常用」（顺带成为该字的一个读音）
#
# 格式：`U+XXXX: 音节  # 汉字 · 备注`，音节一律无声调（同 reading_rare.txt）。
# 本表补进来的读音会一起进 PinyinUtil#allSyllables，所以「这个字有哪几个读音」也认它。
#
# 判定门槛：**歌词里真的会这样唱**才算数。像「骑 jì」（铁骑、千骑、一骑红尘）在古风歌词里
# 高频出现，而两本词典都只收 qí —— 不补的话「骑」被当成单音字，一句里读错也提示不到。
# 反过来，只在引用古诗时才读的古音（如「斜」xiá、「衰」cuī）不进本表：它们在现代汉语里
# 并不常用，真要收的话往这里加一行即可。
