#
# 格式：`U+XXXX: 音节  # 汉字 · 备注`
#   · 一行一个音节；同一个字有多个生僻读音就写几行（如「单」chán / shàn、「朴」piáo / pō）。
#   · **音节一律无声调** —— 声调不参与判定，写了也没用，还省得手抄声调出错。
#   · ü 照常写（如 `nü`），加载时归一成 `v`。
#   · 备注写「什么词里才这么读」，方便以后判断该不该把这条挪走。

# 判定基线（改本表前先读）：出现在 /pinyin/kTGHZ2013.txt 的音节默认**常用**，本表降级其中一部分；
# 只出现在 /pinyin/pinyin.txt 的音节（古音／异体音）默认**生僻**，不必写在这里。
