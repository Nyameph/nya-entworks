喊麦的文件名**没有规律**（不是「作者 - 曲名（原曲名）」那套），所以这一模块**不解析文件名、不归并，也没有作者 / 原曲统计**，倍速那一层回落也没有。它正是因此单独成一块，而不是歌曲里的一个页签。

## 未归档

样子和歌曲的「未归档」一样：一列喊麦，一行一组，上面有工具条。

### 工具条

- 搜索框 + **查询**（按回车也一样）。
- **清空**：清掉搜索框里的字。
- **随机播放**：把这一层待打分的喊麦洗成一个队列，一首一首过。在播放条里定了分，这一首就自动移走、接着放下一首，放完为止。**关掉页面队列就没了**，不会存下来。这一层是空的时会告诉你。
- **重新扫描**：按磁盘现在的样子重新列一遍。
- **添加文件**：多选文件、或者粘一串路径，把外面的一组文件收进来（下面单说）。

### 每一行

- **播放**：弹出播放条，边听边定分。定了分，这一行直接从列表上消失，不用整页重刷。
- **归档**：不播放，直接打开表单定档。
- **删除**（红）：删的是磁盘上的文件，**会进 Windows 回收站**，删错了可以从那里还原，会先让你确认。

### 打分就是归档

定档是把这一组文件（视频、音频、歌词一起）**整个搬进**对应的分数档里，**这一步不能撤销**。

打分那一排按钮给的是全部几个分数档，哪怕某个档的文件夹你还没建。**没建的档选下去，程序会自己把文件夹建出来**，名字就是那个分数本身（5 分就是 `#5`）。想给这个档添个说法，自己去资源管理器里把文件夹名补在分数后面就行——程序认的只是开头那个分数。

和歌曲的未归档有三处不同：没有标签页；随机播放不问你从哪几档抽；没有倍速那一列。

归档前是不是必须打标签，看系统配置页里「喊麦 · 归档前强制打标签」那一项。开了的话，没有标签的按钮会变灰并写明原因。

### 「添加文件」

1. 多选文件，或者粘一串路径。跟它们同名的歌词会自己跟着来。
2. 名字可以**留空**（保持原来的文件名），也可以填一个新名字把这一批合成一组。
3. 按「迁移到未归档」（先放着待打分）或者「归档」（直接定档）提交。

**一次只能处理一组。** 要是你选的文件其实是两首不同的曲子，两个按钮都会变灰，并告诉你分成了哪几组——要么只留一组的文件，要么在上面填个新名字把它们合成一组。

弹窗里面还有几件：

- 文件行右边的 **×** 有三层意思（鼠标移上去会说明）：已经归档的文件是「剔除」，提交后挪进冗余；这次新选的是「本次不处理」，磁盘上不动；已经剔掉的那一行会变成一个 **↩**，点它可以恢复。
- 评分那一排按钮，点一下选中，再点一下取消；这一组现在就在那一档里的按钮是灰的。
- 提交之前会先给你一张确认页，写着旧名改成什么、从哪个目录搬到哪里去；有文件动不了的话整批就不执行，并告诉你卡在哪。

## 喊麦

这里的喊麦**不解析文件名**（文件名没有规律可循），所以一个文件组就是一行，也不会把多个版本并成一行。每次打开都按磁盘现在的样子重新列一遍，显示的是原始文件名。

### 工具条

- 分区下拉：选中就自动查，不用再点「查询」。
- 搜索框：搜文件名，**回车即查**。
- **清空**：分区和关键词一起清掉。
- **查询**。
- **重新同步**：扫一遍磁盘重建记录。你在资源管理器里改过文件名或者挪过分区之后，点它补跑。归档根不在的时候它是灰的。
- **随机播放**：先弹一个小窗口问你想从哪几档里抽（默认全勾），勾好了再开始。它把当前筛选结果里属于这些档的那些洗牌连放，放完为止。**这只在这一次播放里有效，不会存下来。**

### 每一行

- **播放**。
- **修改**：打开一个大弹窗，**一次把一组改完**——改整组的名字、改评分、改标签、补文件都在这一处。名字留空就是保持原名，填了就是把这一组整个换成那个名字。
- **删除**（红）：删盘上的文件，**会进 Windows 回收站**，会先让你确认。

「倍速」那一列只在已归档的这一页有。

### 底下那张「冗余文件」卡

收着的，是改名或者剔除时留下的旧文件（点「展开」才去读，一次读一页）。

- **不想要的可以「移入冗余」——那不是删除。** 被剔掉的文件会挪到成品文件夹下的「冗余」里，原来那一组照常能用。
- 卡片只告诉你文件还在不在盘上——**要删或者搬回来，请去资源管理器里做**；想知道是谁什么时候动的，看左下角的「文件记录」。
